## 決まったこと（2026-11-17、オーナー判断）
- **工事期間を設ける。** 出店は3週間、改装は2週間。
- **標準的なストーリー**：出店してから黒字転換まで、だいたい10〜15週。40週目くらいで初期投資を回収し、2店舗目を出店できる体力がつく。
- **週の結果の画面は、毎回必ず見せる。** 内容は、週間売上高、週間純利益、CF（お金の出入り）。店舗ごとではなく、**全店舗の集計**で見せる。
- **フェーズ1は40週前後。60週までは引っぱらない。**
- **フェーズの移り変わりはシームレス。** ゲームは現在のフェーズを示さず、フェーズのデータも持たない。行動の誘導は資金面などの制約で自然に行う（`docs/decisions/2026-11-17-phases-are-design-only.md`）。
- **計算の順番**は「競合 bot の行動 → 客の来店 → 売上と費用 → 従業員（士気、成長）→ 評判 → お金」でよい。店員を人数で表すことになったため、「従業員」は店員と店長、「成長」は店長の成長と読み替える。
- **工事中の費用**：出店の工事中は家賃がかかる。開店と同時にシステムがデフォルトの人数の店員を雇い、その週から人件費がかかる。改装中は店は営業せず、家賃と店長の人件費がかかる（`docs/decisions/2026-11-17-staff-and-manager.md`）。
- **週の結果の画面に「新聞」を入れる。** 詳しくは #24 で設計する。
- **ゲームの最初の出店も、3週間の工事期間を持つ。** 工事中は売上がなく、会計上はマイナスになる。現金は、工事を決めたときに前金（戻ってこない。払った週に費用）と工事代などを払い、工事中も毎週の家賃が出ていく。減価償却は開店した週から始まり、工事中は設備や内装の減価償却費はかからない（工事中は費用も CF も家賃だけ）。
- 改装中、店員の人件費はかからない。改装後は同じ人数で営業を再開する。

## 決まったこと（2026-11-21、オーナー判断）
- 1週間に操作できる回数に制限はつけない。
- 純利益 ＝ 売上 − 食材費 − 人件費 − 家賃 − 減価償却費 − リース料 − 前金 − 違約金 − その他。
- CF は、その週に実際に増減した現金。税金は入れない。借入はフェーズ1から入れるが、設計は #26 で行い、最初の実装には入れない。
- 自動で進むモードは、ボタンでの進行ができてから作る（#6）。
- 記録：`docs/decisions/2026-11-21-phase1-open-items.md`

## 背景
時間は週単位で、「次の週へ」ボタンで進めるのが全フェーズ共通の基本と決まった。1週間の中で「何を・どの順で」行い、ボタンを押すと何が起きるかを決めないと、ほかのすべての仕組み（客、従業員、損益、bot）の計算の順番が決まらない。

## 提案
**1週間の流れ**

1. **操作の時間**：プレイヤーは操作する（価格の調整、店員の人数、店長の選任・解雇、出店・改装の指示）。何もしなくてもよい。
2. **「次の週へ」ボタン**を押す。
3. **計算**：その週の営業を計算する。順番は「競合 bot の行動 → 客の来店 → 売上と費用 → 従業員（士気、成長）→ 評判 → お金」。
4. **週の結果の画面**（毎回必ず表示）：全店舗の集計で、週間売上高、週間純利益、CF を見せる。あわせて新聞を載せる（#24）。
5. 1に戻る。

**操作が効くタイミング**
- 価格、店員の人数、店長の選任・解雇：次の週の計算から効く。
- 出店：指示してから3週間の工事のあとに開店する。
- 改装（設備・内装・外装・席への投資）：指示してから2週間の工事のあとに効く。

**フェーズ1の標準的な進み方**

| 週 | 起きること |
|---|---|
| 0〜3週 | 出店の工事（3週間）。売上はない。家賃で純利益は赤字。CF も毎週、家賃の分だけマイナス |
| 開店〜10〜15週 | 評判が育つまで赤字。10〜15週で黒字に転換する |
| 〜40週ごろ | 黒字が積み上がり、初期投資を回収する。2店舗目を出せる体力がつく |

- 詳しい流れと、フェーズ2へ進む条件は #21 で設計する。

**週の結果の画面と、店舗損益計算書の関係**
- 週の結果の画面：会社全体（全店舗の集計）の3つの数字。毎週必ず出る。
- 店舗損益計算書（#18）：店舗ごとの費用の内訳。詳しく見たいときに開く。

**自動で進むモード**
- 用意することは決まっている。この issue では「ボタンでの進行」だけを設計する。自動モードの中身は、エピック #6 の側で設計する。

## 楽しさへの効き方
- 効率化の快感：一手打つ → ボタン → すぐ結果、の短い輪で、手応えが毎回返ってくる。
- 数値が伸びる快感：週間売上高と純利益が、週ごとに動くのを確かめられる。赤字から黒字に変わる瞬間が、最初の山場になる。

## トレードオフ
- 得るもの：考える時間に制限がなく、初めての人でも焦らない。
- 諦めるもの：リアルタイムで店が動いている臨場感。放っておけば進む手軽さ（自動モードで補う）。
- 工事期間：出店・改装は、決めてから効くまで待つ。その間もお金は出ていくので、「いつ投資するか」が判断になる。

## もっともらしさのチェック
- 週ごとに売上を締めて見直すのは、店の経営として自然。
- 店を出す・改装するには工事の時間がかかる、開店してすぐは赤字、は常識に沿う。
- 1日の中の時間帯（昼・夜）は扱わない。週の合計として見せる。

## 再現しないものへの配慮
- 「純利益」「CF」は、複雑な会計にしない。税金は入れない。減価償却は2年、残存価値は取得原価の10%（#14）。
