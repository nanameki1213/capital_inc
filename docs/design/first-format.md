# 最初の業態

- 状態：承認済み（2026-11-20、オーナー）
- issue：#20（親エピック #3）
- 層：主 A（関係 B、C）
- フェーズ：1
- 判断の記録：`docs/decisions/2026-11-20-first-format.md`

---

## 1. 決まったこと

- 最初の業態は**1つに固定**する（#20 の案A）。全員が同じ業態で始める。
- 最初の業態は**カフェ**。
- ほかの業態は、bot の会社として街にある。フェーズ4で買収して手に入れる。

## 2. 設計の約束

- 業態は、`docs/design/overview.md` 6.1 の「特徴」（使う食材、調理のしかた、立地、時間帯、客層、接客の形）を最初から持つ。フェーズ4のシナジーの計算に使うため。
- **フェーズ1で計算に使う特徴は、立地との相性だけ。** 残りの特徴はデータとして持つだけにする（2026-11-20、オーナー判断）。
- ゲーム内の業態名・店名はすべて架空にする。実在のチェーンを思わせる名前にしない（`docs/game-design.md` 5.5）。
- 参考にしている Coffee Inc 2 もコーヒー店から始まるので、固有の名前や見た目を似せないように気をつける。

## 3. カフェで決まっていること

| 項目 | 内容 | 設計 |
|---|---|---|
| 設備 | コーヒーの機械（飲み物の数）とオーブン（軽食の数）の2種類。種類ごとに買うかリースかを選べる | `docs/design/equipment-by-format.md` |
| メニュー | システムが用意する（飲み物と軽食） | #16 |
| 立地 | カフェを基準に、立地との相性を作る（例：駅前やオフィス街は相性が良い） | #13 |

## 4. 楽しさへの効き方

- 選択肢が増える快感：最初は1つの業態だけなので、あとで買収して業態が増えたときの驚きが大きい。
- 最初の店の個性は、立地・設備・内装・外装・価格で出す。

## 5. トレードオフ

- 作る量が少なく、バランスを取りやすい。「ほかの業態は買収で手に入れる」という、このゲームの売りがはっきりする。
- 代わりに、遊び始めに業態を選ぶ楽しさはない。
