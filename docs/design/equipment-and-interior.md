# 設備・内装・外装・席への投資

## 1. 目的

出店場所を決めたら、次に設備・内装・外装を選ぶ。開店したあとは、貯まったお金で設備・内装・外装・席に投資する。
これがフェーズ1の「長い輪」（お金を貯める → 投資する → 店の天井が上がる）であり、選択肢が増える快感の主な出どころになる。

## 2. 4つの投資先

| 投資先 | 効果の一行説明 | 効くところ |
|---|---|---|
| 設備（厨房） | 1週間に出せる料理の数が増える。業態ごとに2〜3種類あり、一番弱い設備が出せる数を決める（例：カフェはコーヒーの機械とオーブン） | さばける数の上限 |
| 内装 | 居心地が良くなって満足度が上がり、高い値段でも客が来る | 満足度、価格への許容 |
| 外装 | 店の前を通る人の目にとまり、初めての客が入りやすくなる | 来たい客の数 |
| 席 | 一度に入れる客が増える | さばける数の上限（物件の広さまで） |

## 3. 段階

- 内装と外装は、別々の投資先にする（2026-11-18、オーナー判断）。
- 設備・内装・外装は、それぞれ**4段階**にする（2026-11-18、オーナー判断）。名前は仮で、最低限 / 標準 / 上等 / 最上級。
- 設備は、**業態ごとに2〜3種類**あり、種類ごとに4段階を持つ（2026-11-20、オーナー判断、#25 の案B）。店が出せる数は、**一番弱い設備**で決まる。どの設備がボトルネックかを見つけて直すのが、効率化の楽しさになる。
- 開店時に1つ選ぶ。あとから上の段階に上げられる（差額より少し高くつく）。
- 上の段階ほど値段が急に上がり、効果はゆるやかに増える（G3）。
- **アンロックはない。** 最初から、つねに最上級まで選べる（2026-11-19、オーナー判断）。
- ただし上の段階ほど高いので、**最初は資金の面で選べない**。お金が貯まるにつれて、手が届く段階が上がっていく（資金の制約で自然に誘導する方針：`docs/decisions/2026-11-17-phases-are-design-only.md`）。
- 上等な設備・内装・外装ほど、週の維持費（「その他」の費用）が少し高い。

## 4. 工事期間（決まったこと）

- 出店の工事は3週間、改装の工事は2週間。改装は、設備・内装・外装・席の**どの投資先も2週間**（2026-11-19、オーナー判断）。ゲームの最初の出店も、3週間の工事期間がある。
- 出店の工事中は、売上がなく家賃がかかる。現金も、家賃の分が毎週出ていく。
- 改装（設備・内装・外装・席への投資）の工事中は、店は営業しない。家賃と店長の人件費はかかるが、店員の人件費はかからない。改装が終わったら、同じ人数で営業を再開する。

## 5. お金の払い方（決まったこと）

### 5.1 物件

- 物件は賃貸にする。出店を決めたときに、戻ってこない前金を払う。
- 前金は、払った週にまとめて費用にする。
- 前金と工事代を払えるだけの現金がないと、出店できない。最初の店も同じ。

### 5.2 設備：買うか、リースか

設備は、フェーズ1から「買う」か「リース」かを選べる。内装と外装はリースできず、買うだけ（外装は、内装と同じ扱いと読んでいる）。

| | 買う | リース |
|---|---|---|
| 最初の現金 | 多い | ほぼいらない |
| 毎週の費用 | 減価償却費（開店した週から） | リース料（総額は買うより少し高い） |
| 期間 | なし | 2年（104週）で固定 |
| 途中でやめるとき | 売れば、少しお金が戻る | 残りのリース料をすべて払い、違約金（残りのリース料の1割）を損失として計上する |
| 期間が終わったら | — | 元のリース料の2割で、また2年借りなおせる。返す場合は設備を買いなおす |
| 店を閉めるとき | 売れる | 途中でやめる扱い（他の店には移さない） |

### 5.3 減価償却

- 買った設備・内装・外装は、開店した週から少しずつ費用にしていく（減価償却費）。
- **減価償却は2年（104週）で行う**（2026-11-19、オーナー判断）。リースの期間（2年）とそろう。
- **減価償却が終わったあとの残存価値は、取得原価の10%で統一する**（2026-11-19、オーナー判断）。2年で取得原価の90%を費用にし、10%は帳簿に残り続ける。
- 買った設備を売るときは、そのときの帳簿の額（取得原価 − それまでの減価償却費）で売れる（2026-11-19、オーナー判断）。
- 内装と外装は売れない。店を閉めたら、帳簿に残った分は損失にする（2026-11-19、オーナー判断）。
- 開店したあとの改装で買ったものは、その改装の工事が終わった週から2年で減価償却する、と読んでいる。
- 工事中は、設備・内装・外装の減価償却費はかからない。工事中の費用は家賃だけ。
- このため、週間純利益と CF は一致しない。現金は払った週に出ていき、費用はあとから週ごとに乗る。

## 6. 楽しさへの効き方

- 選択肢が増える快感：お金が貯まるにつれて、手が届く段階が上がっていく。設備を買うかリースか、という資金の使い方を選べる。
- 数値が伸びる快感：投資した店が工事を終えると、客数や売上がはっきり増える。
- 効率化の快感：「席は余っているのに厨房が追いつかない」などを見つけ、足りないほうに投資する。

## 7. トレードオフ

- 投資すると、店の天井（さばける数、取れる値段）が上がる。代わりに手元のお金が減る。回収するまでは数週〜十数週かかり、改装の2週間は売上も止まる。
- 設備に寄せるか、内装に寄せるか、外装に寄せるか：回転で稼ぐ店か、単価で稼ぐ店か、客を呼び込む店か、の方向が変わる。
- 買うかリースか：リースにすると、手元のお金が少なくても早く出店できる。代わりに総額が少し高く、2年間はやめにくい。リースの多い店ほど、閉めるのに現金が要る。

## 8. もっともらしさのチェック

- 良い厨房なら速く多く作れる、きれいな店なら高くても客が入る、目立つ店構えなら通りがかりの客が入る、は常識に沿う。
- 物件の広さを超えて席は増やせない。
- 工事中は営業できない、リースは途中でやめると高くつく、は常識に沿う。

## 9. 再現しないものへの配慮

- 会計は「前金」「減価償却費」「リース料」「違約金」までにとどめる。税金や細かい会計処理は入れない。
- 設備が古くなって入れ替える仕組みは、いまは入れない（2026-11-19、オーナー判断）。故障や事故の出来事も入れない。
