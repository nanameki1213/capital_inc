## 背景
「詰まり」の専用の表示は最低限にし、店舗ごとの店舗損益計算書で「費用がどのくらいかかっているか」から詰まりを見せる、と決まった。この1枚が、フェーズ1でプレイヤーが毎週見る中心の画面になる。フェーズ4では、シナジーで費用の割合が下がることを同じ表で見せる土台になる。

**1枚の形**（1店舗・1週間）

|---|---|---|---|
| 売上 | | 100% | |
| 　食材費 | | % | |

| 　家賃 | | % | |
| 　その他（設備・内装の維持費など） | | % | |

- 売上の横に、客数と客単価を添える（売上 ＝ 客数 × 客単価）。
- 割合には、**目安と比べた色**をつける（例：家賃が売上の1割を大きく超えていたら注意の色）。これが、最低限の「詰まり」の表示になる。
- 週ごとの推移を、小さな折れ線で見せる。
- 期間を「今週 / 直近4週 / 開店から」で切り替えられる。

**用語**
- 「損益計算書」は難しい言葉なので、ゲーム内の名前を別につける（例：「お店の成績表」）。

**効果の一行説明**
- 店舗損益計算書：売上が、どの費用にいくら消えて、いくら残ったかが分かる。

## 楽しさへの効き方
- 効率化の快感：一手打った結果が、割合と先週との差で見える。「人件費の割合が35%から31%に下がった」と数字で確かめられる。
- フェーズ4で同じ表の割合がシナジーで下がるのを見せるための、目を慣らす場所。

## トレードオフ
- 得るもの：1枚見れば店の状態が分かる。原因を自分で読み取る余地が残る。
- 諦めるもの：「ここが詰まっています」と直接教えてくれる親切さ。数字の表が苦手な人には少し固い。

## もっともらしさのチェック
- 売上から費用を引いて利益、という形は誰でも分かる。
- 目安の数字（家賃1割など）は現実の目安に近づけるが、ゲームのバランスを優先する。

## 再現しないものへの配慮
- 複雑な会計・税務は再現しない：税金、消費税、在庫の評価は入れない。減価償却は入れる（2年、残存価値10%：#14）。投資の出費そのものはこの表に載せず、CF の側で見せる。
