# 店員と店長の扱い、工事中の費用、新聞についての判断

- 日付：2026-11-17
- 判断した人：オーナー
- 関係する issue：#17（従業員）、#12（週の進行）。#2（contracts）、#4（権限移譲）、#18（店舗損益計算書）、#19（競合 bot）にも影響する。

## 判断内容

1. **店員は、人数と時給だけで表す。** 1人ずつの名前や能力値は持たない。
2. **名前と能力値を持つのは、店長。**
3. 開店と同時に、システムがデフォルトの人数の店員を雇う。その週から人件費がかかる。
4. 店長は、プレイヤーが選任しない限りいない。いないあいだは、プレイヤーが直接運営できる。
5. 店長は、その店が開店した週から雇える。
6. 出店の工事中は、家賃がかかる。
7. 改装中は、店は営業しない。家賃と店長の人件費はかかる。
8. 週の結果の画面に「新聞」を入れる。重大な要素なので、別の issue で詳しく設計する。
