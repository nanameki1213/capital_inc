- 確認日はすべて **2026-11-16**。
- 要点は自分の言葉でまとめたもので、原文の引用ではありません。
- 「確認方法」の欄の意味

  - **検索要約のみ**：検索結果の要約だけで、本文は確認できていない。設計の根拠にするときは再確認が必要。

## 1. 外食大手ホールディングスの効率化・シナジー

概要レベルの調査です。精緻な分析はしていません。

### H1. ゼンショーホールディングス「ビジネスモデル」（公式サイト）

- URL: https://www.zensho.co.jp/jp/mmd/
- 種類: 一次資料（企業公式） / 確認方法: 本文確認
- 要点
  - 原材料の調達、製造・加工、物流、店舗での販売までを、自社で企画・設計・運営する一貫した仕組みを持つ。
  - 調達：産地まで行って食材の仕様を決める。生産にも関わる。
  - 製造：販売の予測をもとに、必要な分だけ作って在庫の無駄を減らす。
  - 物流：温度と期限を管理しながら、常時配送する。拠点網が非常時の備えにもなる。
  - 店舗：外食だけでなく、中食・小売・介護など複数の分野に同じ仕組みを使う。
- ゲームへのヒント
  - 「調達 → 製造 → 物流 → 店舗」を1本の流れとして持ち、**業態が増えても同じ流れに載せる**と効率が上がる、という骨格。
  - 需要の予測と生産をつなげると無駄（廃棄・在庫）が減る。
- 確認できなかったこと：買収した会社にこの仕組みをどう適用するかは、このページには書かれていない。

### H2. すかいらーくホールディングス「すかいらーくの強さの仕組み」（公式IR・個人投資家向け）

- URL: https://corp.skylark.co.jp/ir/individual/cuisine/
- 種類: 一次資料（企業公式IR） / 確認方法: 本文確認
- 要点
  - グループ全体の店舗規模を使って、食材をまとめて買う。食材の調達とメニュー開発を一体で進める。
  - 複数の自社工場（セントラルキッチン）で、食材のカットやソース作りなどの下処理をまとめて行う。店での調理の負担が減り、品質がそろう。
  - 自社の配送網で、下処理済みの食材を店に届ける。
  - 何でもそろう業態から専門店まで、複数のブランドを同じ仕組みの上で運営する。
  - 販売データの分析をメニュー開発に使う。宅配・持ち帰りも同じ店舗網で広げる。
- ゲームへのヒント
  - **まとめ買い・工場・配送の3つを、業態をまたいで共有する**のがシナジーの基本形。
  - 工場1つが多数の店をまかなう＝店が増えるほど工場の固定費が薄まる。

### H3. コロワイド「コロワイドとは」（公式サイト）

- URL: https://www.colowide.co.jp/about/
- 種類: 一次資料（企業公式） / 確認方法: 本文確認
- 要点
  - 商品開発、食材の調達、製造・加工、物流を一貫して管理する機能を、グループ共通で持つ。店舗運営以外をまとめて引き受ける形。
  - グループでまとめて調達した食材を出発点にしてメニューを開発し、コスト削減と価値の向上を両立させる。
  - 工場がグループ全体のセントラルキッチンとして動き、店の仕込みを減らす。
  - 買収を成長の主な手段にして、居酒屋中心から、焼肉・定食・回転寿司・カフェ・給食などへ業態を広げてきた。
  - 買収で見込む効果の例：業態の拡大、商品の販売強化、出店開発力の向上、仕入れと物流のコスト低減。
- ゲームへのヒント
  - 「共通の裏方（調達・製造・物流）を持っている会社が、新しい業態を買ってきて裏方に載せる」という買収の型。
  - 買収の効果は、コストだけでなく**出店力や商品の横流用**にもある。

### H4. サイゼリヤ「自社工場の取り組み」（公式サイト）

- URL: https://www.saizeriya.co.jp/corporate/effort/
- 種類: 一次資料（企業公式） / 確認方法: 本文確認
- 要点
  - 素材の開発、原料の調達、加工、配送、店での提供までを自社でつなげ、間に入る業者を減らして品質と価格を自分で決められるようにしている。
  - 定番の人気商品に絞っているので、需要を読みやすく、計画的に大量に作れる。
  - 工場で「店ですぐ使える形」まで加工して届けるので、店の調理・片づけ・保管の手間と提供時間が減る。
- ゲームへのヒント
  - **メニューを絞るほど工場の効率が上がる**（品ぞろえの豊かさとのトレードオフ）。
  - 工場の目的は原価だけでなく、**店の作業を減らすこと**でもある。

### H5. クリエイト・レストランツ・ホールディングス（フィスコ 企業調査レポート）

- URL: https://www.fisco.co.jp/wordpress/wp-content/uploads/FISCO/createrestaurants20250423.pdf
- 種類: 二次資料（アナリストレポート） / 確認方法: **検索要約のみ**（公式サイトは取得がタイムアウトした）
- 要点
  - 立地ごとに、合う業態を組み合わせて出す（多数のブランド × 多数の立地）。
  - 買収で成長性のある業態を取り込みつつ、各社の個性と自律を残す「連邦」型のグループ運営を特徴にしている。
- ゲームへのヒント
  - H1〜H3 の「がっちり統合する」型とは反対側の、**ゆるく束ねる**型がある。統合の度合いを選ばせる案（overview 6.3）のもと。

### H6. すかいらーくホールディングスの歴史（The 社史）

- URL: https://the-shashi.com/tse/3197/decisions/
- 種類: 二次資料（企業史の解説サイト） / 確認方法: **検索要約のみ**
- 要点
  - 不採算の店を、立地や建物を変えずに別の業態へ看板を掛け替える「業態転換」を長く続けている。
  - 和・洋・中の複数ブランドを、購買・製造・物流・店舗をつなげた共通の基盤に載せている。
- ゲームへのヒント
  - 業態を多く持つと、**不振店を閉めずに別業態へ変える**という選択肢が生まれる。

### H7. コロワイド セントラルキッチンの統合（The 社史）

- URL: https://the-shashi.com/tse/7616/decisions/central-kitchen-integration-1994/
- 種類: 二次資料（企業史の解説サイト） / 確認方法: **検索要約のみ**
- 要点
  - 工場と物流の機能が、のちの買収の前提（買った会社を載せる土台）になった。
  - 一方で、買収される側にとっては「工場での調理に切り替えられること」が反対の理由にもなった事例がある、という指摘。
- ゲームへのヒント
  - **シナジーの源が、そのまま買収への反対理由にもなる**。「店で作ること」が売りのブランドに工場を押しつけると個性が落ちる、というトレードオフのもと。

## 2. 飲食店経営の「誰でもなんとなく知っている常識」

### C1. マネーフォワード クラウド「飲食店のFL比率とは？計算方法や目安を解説」

- URL: https://biz.moneyforward.com/restaurant/basic/630/
- 種類: 解説記事 / 確認方法: 本文確認
- 要点
  - 食材費（F）と人件費（L）が飲食店の2大コスト。この合計が売上に占める割合を見る。
  - 目安は業態によって違う。
- 注意：記事内の目安の数字に、取得した範囲では食い違いが見られた（業態別の合計が60%前後とする箇所と、もっと低い数字の箇所）。**数字は使わず、「食材費と人件費が2大コスト」という考え方だけ**を参考にする。

### C2. マネーイズム「飲食店経営に欠かせない経営指標！」

- URL: https://www.all-senmonka.jp/moneyizm/management/143/
- 種類: 解説記事 / 確認方法: 本文確認
- 要点
  - 売上は「席数 × 回転率 × 満席率 × 客単価 × 営業日数」に分解できる。
  - 回転率は「1日の客数 ÷ 席数」。注文・提供・片づけを速くすると上がる。
  - 食材費と人件費の合計は、売上の55〜65%あたりが目安とされる。
  - 食材費と人件費を削りすぎると、質の低下や人手不足で満足度が下がり、かえって負ける。
- ゲームへのヒント
  - 売上の分解式は、フェーズ1の「どこが詰まっているか」を見せる土台になる。
  - **コストを削りすぎると客が離れる**、というトレードオフ。

### C3. 飲食店ドットコム「飲食店の家賃の目安を考える」

- URL: https://www.inshokuten.com/foodist/article/7535/lead/
- 種類: 解説記事 / 確認方法: 本文確認（冒頭部分のみ。検証の結論部分は未取得）
- 要点
  - 「家賃は売上の1割以下」「家賃は3日で稼ぐ」という昔からの目安がある。
- ゲームへのヒント
  - 好立地は客が多いが家賃が重い、という判断の物差しになる。

### C0. 出典なしで前提にする常識（このプロジェクトでの整理）

特定の資料にもとづかない、一般的な感覚として前提にするものです。出典が必要になったら追加で調べます。

| 常識 | ゲームでの扱い |
|---|---|
| 値上げすると客が減る。値下げすると客は増えるが、もうけは薄くなる | 価格と客数の関係 |
| 好立地は客が多いが、家賃が高い | 立地と家賃の関係 |
| 人手が足りないと提供が遅れ、行列・取りこぼし・不満が出る。多すぎると人件費が重い | 人手と回転率の関係 |
| 席が埋まると、それ以上は客を入れられない | 店の天井 |
| 仕入れすぎると廃棄が出る。少なすぎると品切れで売り逃す | 仕入れ量の判断 |
| まとめて買うと安くなる | まとめ買い・原料の共通化 |
| おいしい・早い・安いは、全部は同時に取れない | メニューと価格のトレードオフ |
| 昼と夜、平日と休日で、客の数と目的が違う | 営業時間とシフト |
| 評判は少しずつ上がり、落ちるときは早い | 満足度と客数の関係 |
| 近くに似た店が増えると、客を取り合う | 出店の食い合い |

## 3. 経営シミュレーション・放置ゲームの仕組み

### G1. Coffee Inc 2（App Store の説明と更新履歴、レビュー）

- URL: https://apps.apple.com/us/app/coffee-inc-2/id1573482724
- 種類: 一次資料（開発元による説明）＋利用者レビュー / 確認方法: 本文確認
- 要点
  - 1店舗から始め、メニュー・価格・内装・設備を自分で決める。
  - **権限移譲が段階になっている**：店長に日々の運営を任せる → 本社の部門（人事、財務、マーケティング、商品、技術など）を作る → 役員を雇って会社全体を任せる。役員には株式報酬で報いる。
  - 上場や買収を、投資銀行とのやり取りとして行う。取締役会、役員報酬、配当の判断がある。
  - 損益・資産・現金の流れの3つの報告書で経営を見せる。
  - **倒産には猶予がある**：支払いができなくなってもすぐには終わらず、数週間の猶予期間と警告、立て直しの手段がある。
  - 競合の店と市場を取り合う。
  - レビューの傾向：序盤は操作が多くて難しく、後半は楽になる。店長や役員に任せる仕組みは好評。帝国を作り終えたあとの長期目標が足りないという声がある。
- ゲームへのヒント
  - 権限移譲の段階（店長 → 部門 → 役員）は、このゲームのフェーズ構成とほぼ同じ形。
  - 倒産の猶予期間は、倒産と放置の両立（overview 5章）のもと。
  - 「後半にやることがなくなる」という弱点を、このゲームは**ホールディングス段階のシナジー**で埋める。

### G2. Gaming Route「Coffee Inc 2 Guide」

- URL: https://gamingroute.com/4224-2
- 種類: 二次資料（非公式の攻略記事） / 確認方法: 本文確認（記事中の具体的な数字は他の資料で裏づけできていない）
- 要点
  - 出店は人通りと家賃と競合の近さで選ぶ。近くに自分の店を固めると効くが、食い合いに注意する。
  - 有能な店長は店の仕事をすべて引き受けられる。経験を積んだ店長を新店に移すと立ち上がりが早い。
  - 本社を持つと、店の遠隔管理、商品開発、販促などができるようになる。
  - 上場はお金が入るが、持ち分が減る。借入は速いが、金利と借りすぎに注意。
  - 役員に運営を任せて戦略に集中できるが、重要な出来事には自分で対応する必要が残る。
- ゲームへのヒント
  - **育った店長を新店に回す**＝人材が拡大の速度を決める。
  - 任せても「大事な判断だけは自分に上がってくる」形。

### G3. Anthony Pecorella「The Math of Idle Games, Part I」（Game Developer／初出は Kongregate 開発者ブログ）

- URL: https://www.gamedeveloper.com/design/the-math-of-idle-games-part-i
- 種類: ゲームデザインの解説記事 / 確認方法: 本文確認
- 要点
  - 設備の値段は、持っている数に対して指数的に上がる。生み出す量は、数に対して直線的に増える。
  - 最初は生産が値段を追い越すが、やがて値段が追いつけなくなり、**自然に壁ができる**。
  - 一定数ごとの倍率ボーナスなどで、壁を一時的に押し返す。ボーナスの位置を設備ごとにずらすと、「次に何を買うか」の優先順位が入れ替わって、選ぶ楽しさが続く。
  - リセットと引き換えの永続ボーナス（プレステージ）で、さらに先へ進めるようにする。
- ゲームへのヒント
  - 「コストは急に上がり、効果はゆるやかに増える」組み合わせが、フェーズごとの天井（overview 4章）の基本。

### G4. Anthony Pecorella「The Math of Idle Games, Part III」（Game Developer）

- URL: https://www.gamedeveloper.com/design/the-math-of-idle-games-part-iii
- 種類: ゲームデザインの解説記事 / 確認方法: 本文確認
- 要点
  - リセットを重ねてはしごを登る感覚が、放置ゲームの中毒性のもと。数字の暴走を抑える役目もある。
  - オフライン中の稼ぎは、上限時間を設ける作品と、設けない作品がある。上限があると、放置時間への依存が減る。
  - 新しい通貨や仕組みを足して、数字を抑え直す作品がある。節目の倍率は、進みが一気に速くなる瞬間を作る。
- ゲームへのヒント
  - オフライン進行の上限という考え方。
  - 「新しい層を足して伸び方を仕切り直す」＝このゲームではフェーズ移行がその役目。

### G5. Eric Guan「Idle Game Design Principles」

- URL: https://ericguan.substack.com/p/idle-game-design-principles
- 種類: ゲームデザインの解説記事 / 確認方法: 本文確認
- 要点
  - 「戻ってくる周期」の違う仕組みを複数持たせる（数十分、数時間、数日）。よく触る人も、たまにしか触らない人も、それぞれ手応えを得られる。
  - 効果もコストも指数的に増やし、コストの伸びを少しだけ大きくすると、手応えを保ちながら進みが自然に遅くなる。
- ゲームへのヒント
  - 権限移譲が進むほど「戻ってくる周期」が長くなる（店は毎日、会社は毎週、グループは毎月）、という設計の裏づけ。

### G6. Wikipedia「Incremental game」

- URL: https://en.wikipedia.org/wiki/Incremental_game
- 種類: 百科事典 / 確認方法: 本文確認
- 要点
  - 手作業から始まり、自動で稼ぐ仕組みを買い足していくジャンル。
  - オフライン中も進む仕組みは、あとから広まった。
  - 多くの作品には失敗状態がなく、気楽に続けられることが魅力とされる。
- ゲームへのヒント
  - 放置ゲームはふつう「負けない」。**倒産がありうる**このゲームは、そこをどう両立させるかが独自の課題になる（overview 5章）。
